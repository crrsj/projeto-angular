# Helpdesk System 🚀 (Em Desenvolvimento)

Sistema de gestão de chamados completo desenvolvido para o gerenciamento de atendimentos, suporte a clientes e rastreamento de interações históricas.

## 📋 Status do Projeto
* **Status atual:** Em desenvolvimento ativo
* **Foco:** Construção de uma solução full-stack robusta integrando arquitetura moderna de front-end e back-end.

## 🛠️ Tecnologias Utilizadas
* **Front-end:** Angular (Standalone Components), TypeScript, Tailwind CSS, RxJS, Formulários Reativos.
* **Back-end:** Java, Spring Boot, API REST.
* **Integrações Externas:** Consumo de serviços de terceiros, incluindo a API do ViaCEP para preenchimento automatizado de endereços.

## 💡 Funcionalidades Principais
* **Interface Master-Detail:** Visualização unificada que combina detalhes do chamado, formulários de interação e histórico de respostas.
* **Busca Dinâmica por Protocolo:** Sistema de consulta otimizado para localizar chamados rapidamente na base de dados.
* **Gerenciamento de Respostas:** Envio e rastreamento de novas interações e status de atendimento em tempo real.
* **Validações Reativas:** Tratamento de dados de entrada diretamente no front-end com feedback visual para o usuário.
